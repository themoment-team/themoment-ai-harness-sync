# 대시보드 사용법

로그인하면 GitHub App이 설치되어 있고 본인에게 `write`, `maintain`, `admin` 권한이 있는 레포만 표시됩니다. GitHub App 설치 범위 밖의 레포나 읽기 전용 권한 레포는 표시되지 않습니다.

레포를 선택한 뒤 동기화 활성 상태와 항목을 변경하면 대시보드가 실제 `.harness/sync.yml`과의 diff를 보여 줍니다. **설정 PR 만들기**를 누르면 변경은 별도 브랜치에서 PR로 생성됩니다.

## 지금 동기화

설정 PR이 병합된 뒤 **지금 동기화**를 누르면 해당 레포 하나만 동기화하도록 GitHub Actions를 실행합니다.

- 동기화가 비활성화된 레포는 요청할 수 없습니다.
- 열린 sync PR이 있거나 최근 요청이 있으면 기존 작업으로 이동합니다.
- 같은 레포의 실행은 순서대로 처리됩니다.

동기화 요청 결과는 해당 레포의 sync PR과 GitHub Actions 실행 화면에서 확인합니다.
